- Script: gerber-to-dxf.py
- Documentation: README.md
- Prompt notes: CODEX_PROMPT.txt

Project purpose:
- Generate one DXF file from fabrication files in the current folder.
- Output file format: <project>-outline-mounting-holes.dxf
- DXF layers:
  - OUTLINE: board profile from the detected outline/profile Gerber geometry
  - MOUNTING_HOLES: selected drill holes as CIRCLE entities

Current behavior requirements:
1. Auto-detect input files:
- Edge profile: *-Edge_Cuts.gbr, with fallback detection for RS-274X profile Gerbers and P-CAD Gerbers that contain an embedded %LNBoard*% layer.
- Drill files: *-PTH.drl, *-NPTH.drl, or generic .drl / .DRL files when present.

2. Geometry handling:
- Preserve board outline geometry from Gerber (LINE/ARC).
- Honor modal Gerber D01 / D02 / D03 state, not only explicit D-codes repeated on every coordinate line.
- For P-CAD Board-layer input, read the Board layer only and ignore unrelated copper / silk / annotation geometry.
- Read source units correctly (inch/mm) and write DXF in millimeters.
- Support zero-suppressed drill coordinates, using Gerber numeric format hints when drill files do not declare enough coordinate format detail.
- Keep original coordinate orientation from fabrication files.

3. Hole filtering CLI:
- Use command-line flags:
  - --min : minimum drill diameter in mm (default: 3.0)
  - --max : maximum drill diameter in mm (default: none / no maximum)
- Validate:
  - --min >= 0
  - --max >= 0 when provided
  - --max >= --min when provided

4. Runtime output:
- On normal run, script prints command-line help text and then summary:
  - output filename
  - outline entity count
  - hole count using active filter
  - diameters used
